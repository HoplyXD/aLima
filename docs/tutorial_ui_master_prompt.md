# UI Master Prompt

Use this prompt when redesigning any in-game UI surface in aLima, especially the tutorial, HUD, menus, popups, inventory, and hard-coded utility screens.

## Master Prompt

Completely redesign the existing game UI while preserving all gameplay functionality, scripts, layouts, interactions, controls, and menu flow. Do not remove features. Do not break existing behavior. The goal is a full visual upgrade only: style, hierarchy, spacing, framing, motion, and presentation.

The interface should feel like a premium original fantasy RPG and roguelike UI inspired by the readability, hierarchy, ornamentation, and polish of high-end MOBA and PC game interfaces, but it must remain fully original. Do not copy Riot Games assets, layouts, icons, textures, or art. Take only the broad design principles: strong hierarchy, elegant framing, clear states, satisfying feedback, and a premium client-like finish.

The world identity is medieval, archaeological, museum-like, handcrafted, and softly magical. The UI should feel discovered inside an old archive, relic workshop, or ancient catalog room rather than a modern app. It should communicate craftsmanship, history, and mystery.

Use muted earthy tones throughout. The palette should lean on dark walnut brown, burnt umber, leather brown, bronze, antique gold, warm beige, old paper, dark olive, moss green, deep slate, iron gray, faded copper, ancient emerald, and dusty crimson for rare warnings only. Avoid bright saturated colors, pure white, pure black, neon accents, flat blue buttons, and sci-fi styling.

Every panel should feel handcrafted and premium. Use carved wooden borders, bronze corner ornaments, subtle engraved patterns, worn leather textures, parchment interiors, layered frames, ambient shadow, soft highlights, and gentle depth. No plain rectangles. Corners should be softened and decorative, with a relic-container look rather than a modern software window look.

Redesign all buttons with a layered, beveled, metallic, engraved-plaque feel. Buttons should have clear idle, hover, pressed, disabled, and selected states. Hover should create a soft golden glow. Pressed should sink inward. Disabled should look faded and old. Selected should read as bronze-highlighted and intentional. Buttons should feel satisfying to use while staying readable and elegant.

Use fantasy-readable typography. Headers should feel serif, elegant, and archival. Body text should be readable and grounded, not modern rounded UI text. Numbers should remain clean and legible while still fitting the ornamental style.

Redesign every icon so the set feels unified. Icons should resemble engraved metal, carved stone, relic sketches, or museum catalog symbols. Keep line weight consistent and the shapes handcrafted. Avoid generic flat app icons.

Add restrained but meaningful UI animation. Use fades, slight scale, soft glow, gentle slide-in motion, page-like reveals, subtle dust particles, small bounce on emphasis, and ease-in-out transitions. The UI should feel alive, tactile, and physical, but never noisy or distracting. Motion should support comprehension and atmosphere.

Redesign the entire tutorial UI to feel like pages from an old explorer's journal or field notebook. Tutorial windows should be immersive rather than intrusive. Use decorative borders, handwritten dividers, parchment paper, ancient symbols, museum notes, margins, soft shadows, and small illustrative accents. The tutorial should teach clearly while preserving the fantasy archive mood.

Include all hard-coded UI in the same style language so the whole game feels coherent. This includes any UI built directly in scenes or scripts instead of data-driven assets: tutorial prompts, dialogue windows, notifications, objectives, achievements, warnings, confirmations, quest updates, HUD elements, health, currency, inventory buttons, interaction prompts, loading screens, pause menu, settings, save menus, trackers, top bars, popups, fallback controls, and any other fixed overlays. These pieces should still behave exactly the same, but visually they must match the redesigned system.

The inventory must be redesigned as a heavy wooden chest or relic case. Slots should be bronze-framed, engraved, and clearly separated. Empty slots should feel like dark parchment or aged leather. Hovered slots should glow softly in gold. Selected slots should have an ancient illuminated frame. Rare artifacts should carry a subtle magical aura. Tooltips should resemble manuscript catalog cards on aged paper. Add better spacing, decorative separators, category headers, rarity borders, and cleaner organization while preserving the current inventory logic.

All popup windows should become parchment sheets mounted on carved wood with bronze fasteners. This includes tutorial popups, dialogue boxes, notifications, objectives, achievements, warnings, confirmations, quest updates, and any similar transient UI. Use fade, slight scale, and soft easing for entrance and exit. Keep the popups readable, elegant, and consistent with the larger UI language.

Replace modern scrollbars with carved wooden rails and bronze handles. Replace default checkboxes with ancient engraved squares and a gold checkmark. Use carved rails and bronze knobs for sliders. Use decorative medieval dropdown frames with parchment lists and soft hover highlights. Make every standard control type feel like part of the same handcrafted UI system.

Make transitions polished everywhere. No instant state changes unless absolutely required by usability. Favor fade, scale, glow, slide, and small bounce motions with subtle timing. Microinteractions should feel premium: hover glow, click depth, success shimmer, muted crimson error feedback, sliding notifications, smooth inventory opening, and tooltip fade-up motion.

Keep the entire interface visually consistent across all screens so it feels like one archaeological workshop UI system. No default engine UI, no mismatched styles, no modern operating-system aesthetics. The final result should be cohesive, premium, readable, and atmospheric.

The restored and unrestored artifact cards must be visually corrected and clearly differentiated. Unrestored cards should feel unfinished, dustier, and more workmanlike, with a rougher frame and a sense that the artifact still needs restoration. Restored cards should feel complete, honored, stabilized, and more refined, with a cleaner frame and calmer presentation. Both states must remain readable, visually polished, and aligned with the same original medieval archaeological style.

Preserve all gameplay functionality and interactive logic exactly as-is. Only redesign visuals, spacing, styling, animation, hierarchy, and presentation. Do not remove any UI elements. Do not change scripts, interaction flow, or feature coverage. If a screen is already functional, upgrade it rather than replacing it.

## Output Expectations

- Keep the UI original while borrowing only broad readability and polish principles from premium fantasy PC interfaces.
- Use muted medieval and archaeological colors, materials, and ornamentation.
- Apply subtle, tasteful animation and microinteraction polish.
- Redesign hard-coded UI alongside tutorial and menu UI so the full experience feels unified.
- Fix restored and unrestored artifact cards so their states are clearly distinct and premium-looking.
- Preserve all functionality, logic, layouts, and interactions.
